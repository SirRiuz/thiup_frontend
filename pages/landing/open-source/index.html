Open source

A privacy promise you don't have to take on faith.

Why the code is public

Thiup asks you to trust it with sensitive conversations. The only honest way to earn that trust is to show the work: the code that runs Thiup is public, so "we don't track you" is something you can verify, not something you have to believe.

What you can audit

The repository shows how masks are derived and why they can't be traced back to you, how the feeds rank threads without ad incentives, how uploads and reports are handled, and what the server stores — and, more importantly, what it never stores.

A small, independent project

Thiup has no investors and no data business. It is built and run by people who think an anonymous, calm corner of the internet should exist.

Open to community contributions

Thiup improves in the open: anyone can propose ideas, report bugs, discuss changes and submit code. Every contribution from the community — an audit, a fix, a translation, a new feature — makes the platform better and safer for everyone.

You don't need permission to start: open an issue or send a pull request on GitHub.
